# Snoopy Cumpleaños 3D

## Archivos
- index.html
- styles.css
- script.js
- assets/snoopy-fiesta.png

## Cómo abrirlo
1. Descomprime el ZIP.
2. Abre `index.html` en Chrome, Edge o Firefox.
3. Pulsa **¡Lanzar fiesta!** para lanzar confeti y globos.
4. Mueve el mouse sobre la escena para ver el efecto 3D.
5. Pulsa **Pedir un deseo** para abrir la sorpresa.

No necesita servidor ni Node.js para funcionar.
